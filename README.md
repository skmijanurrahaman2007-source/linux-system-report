# Linux System Report

A small bash script that saves basic system info to a text file.

It collects:
- hostname
- kernel version
- disk usage
- memory usage
- top running processes

## How to run

```
git clone https://github.com/skmijanurrahaman2007-source/linux-system-report.git
cd linux-system-report
bash system_report.sh
cat system-report.txt
```

The output is saved in `system-report.txt`.

## Files

- system_report.sh - the script
